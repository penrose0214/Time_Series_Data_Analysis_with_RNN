# AR, ARMA, ARIMA 정리

이 디렉터리의 예제는 대중교통 승차량 시계열에 대해 차분과 `ARIMA`를 적용하는 흐름을 다룬다.  
핸즈온 머신러닝에서는 코드 예제가 간단히 지나가서, 실제로 `ARIMA`를 언제 쓸 수 있는지와 그 전에 무엇을 확인해야 하는지가 잘 드러나지 않는다. 이 문서는 그 부분을 흐름 중심으로 정리한 메모다.

## 1. AR, ARMA, ARIMA의 차이

### AR (AutoRegressive)

현재 값을 과거 값들의 선형 결합으로 설명하는 모델이다.

- 예: 오늘의 승차량은 어제, 그제, 지난주의 승차량과 관련이 있다.
- 형태: 현재값 = 과거값들의 조합 + 오차

즉, 과거 관측값 자체를 이용해 현재를 예측한다.

### ARMA (AutoRegressive Moving Average)

`AR`에 더해 과거 예측 오차의 영향도 함께 반영하는 모델이다.

- `AR`: 과거 값의 영향
- `MA`: 과거 오차의 영향

즉, `ARMA`는 "과거 값 + 과거 오차"로 현재를 설명한다.

다만 `ARMA`는 일반적으로 **정상성(stationarity)** 을 만족하는 시계열에 적용하는 모델이다.

### ARIMA (AutoRegressive Integrated Moving Average)

`ARMA`에 차분(`I = Integrated`)을 추가한 모델이다.

- `AR`: 과거 값의 영향
- `I`: 차분을 통해 비정상 시계열을 정상 시계열로 바꾸는 단계
- `MA`: 과거 오차의 영향

즉, `ARIMA`는 원본 데이터가 바로 정상적이지 않더라도, **차분을 통해 정상성에 가깝게 만든 뒤** `ARMA` 구조를 적용하는 모델이라고 보면 된다.

## 2. ARIMA를 적용하기 위한 핵심 조건

실무적으로 가장 중요한 조건은 다음이다.

1. 시계열이 시간 순서대로 정렬되어 있어야 한다.
2. 관측 간격이 일정해야 한다.
3. 모델링 대상 시계열이 정상성이 있거나, 차분 후 정상성에 가까워져야 한다.
4. 과거 값과의 상관 구조가 어느 정도 있어야 한다.

여기서 특히 중요한 것이 **정상성**이다.

## 3. 정상성이란 무엇인가

정상성이 있다는 것은 시계열의 통계적 성질이 시간에 따라 크게 변하지 않는다는 뜻이다.

실무적으로는 보통 다음을 본다.

- 평균이 시간에 따라 크게 변하지 않는가
- 분산이 시간에 따라 크게 변하지 않는가
- 자기상관 구조가 시간에 따라 크게 변하지 않는가

예를 들어 추세가 강하게 증가하거나 감소하는 데이터, 계절성이 강하게 남아 있는 데이터는 보통 그대로는 정상적이지 않다고 본다.

## 4. ARIMA 적용 전 확인 절차

`ARIMA`는 그냥 바로 넣는 모델이 아니라, 보통 아래 순서로 확인한다.

### 1. 시계열 준비

- 날짜 인덱스로 정렬
- 중복 제거
- 결측치 확인
- 관측 주기 명시

예를 들어:

```python
rail_series = df.loc["2019-01-01":"2019-05-31", "rail"].asfreq("D")
```

`asfreq("D")`는 시계열의 관측 간격을 하루 단위로 명시해 준다.

### 2. 시각적으로 정상성 의심

먼저 그래프를 보고 아래를 확인한다.

- 전체적으로 우상향/우하향 추세가 있는가
- 주기적 반복이 강한가
- 분산이 구간마다 크게 달라지는가

이 단계는 정식 검정은 아니지만 매우 중요하다. 추세와 계절성이 눈에 보이면 원본 시계열은 대개 그대로 `ARMA`에 넣기 어렵다.

### 3. 정상성 테스트

대표적으로 `ADF(Augmented Dickey-Fuller)` 검정을 많이 쓴다.

- 귀무가설: 단위근이 있다, 즉 비정상적이다
- p-value가 충분히 작으면: 정상성 쪽으로 해석

보완적으로 `KPSS` 검정을 같이 보기도 한다.

- 귀무가설: 정상적이다
- p-value가 충분히 작으면: 비정상성 쪽으로 해석

즉:

- `ADF`는 비정상성을 기본 가정으로 시작
- `KPSS`는 정상성을 기본 가정으로 시작

둘을 같이 보면 해석이 더 안정적이다.

### 4. ACF/PACF 확인

`ACF(autocorrelation function)`와 `PACF(partial autocorrelation function)`는 자기상관 구조를 확인하는 도구다.

- `ACF`: 현재값과 과거 시차 값들의 상관
- `PACF`: 중간 시차의 영향을 제거하고 남는 직접 상관

이걸 보는 이유는:

- 시계열에 자기상관성이 실제로 있는지 보기 위해
- 차분이 필요한지 감 잡기 위해
- `p`, `q` 값을 고를 때 힌트를 얻기 위해

예를 들어:

- `ACF`가 아주 천천히 감소하면 비정상성을 의심할 수 있다.
- 계절 주기마다 큰 스파이크가 보이면 계절성이 남아 있음을 의심할 수 있다.

## 5. 정상성이 없으면 어떻게 하나

정상성이 없으면 **차분(differencing)** 을 사용한다.

차분은 현재값과 이전값의 차이를 보는 것이다.

### 1차 차분

```python
series.diff()
```

의미:

- `x_t - x_(t-1)`

주로 추세를 제거하는 데 사용한다.

### 계절 차분

```python
series.diff(7)
```

의미:

- `x_t - x_(t-7)`

7일 주기 데이터라면 "지난주 같은 요일"과의 차이를 보는 것이다. 요일 패턴처럼 반복되는 계절성을 줄이는 데 유용하다.

### 차분 후 다시 확인

차분을 한 뒤에는 다시 아래를 본다.

1. 그래프
2. ADF/KPSS 같은 정상성 검정
3. ACF/PACF

즉, 차분은 한 번 하고 끝내는 게 아니라 **정상성에 가까워졌는지 재확인**해야 한다.

## 6. ARIMA를 적용하는 실제 흐름

아래 흐름으로 생각하면 가장 덜 헷갈린다.

### Step 1. 시계열을 시간축 기준으로 정리한다

- 날짜 정렬
- 인덱스 설정
- 중복 제거
- 고정 주기 설정

### Step 2. 원본 시계열을 그려 본다

- 추세가 있는가
- 계절성이 보이는가
- 분산이 안정적인가

### Step 3. 정상성 검정과 ACF/PACF를 본다

- ADF
- 필요하면 KPSS
- ACF/PACF

### Step 4. 비정상적이면 차분한다

- 추세가 강하면 1차 차분
- 계절성이 강하면 계절 차분
- 둘 다 있으면 일반 차분 + 계절 차분 조합 고려

이때 `ARIMA(p, d, q)`의 `d`는 일반 차분 횟수이고,  
계절 모델에서는 `seasonal_order(P, D, Q, s)`의 `D`가 계절 차분 횟수다.

### Step 5. 차분 후 다시 정상성을 확인한다

- 그래프 재확인
- ADF/KPSS 재확인
- ACF/PACF 재확인

### Step 6. 모델 차수를 정한다

- `order=(p, d, q)`
- `seasonal_order=(P, D, Q, s)`

여기서:

- `p`: 일반 AR 차수
- `d`: 일반 차분 횟수
- `q`: 일반 MA 차수
- `P`: 계절 AR 차수
- `D`: 계절 차분 횟수
- `Q`: 계절 MA 차수
- `s`: 계절 주기

### Step 7. 모델 학습 후 잔차를 확인한다

좋은 모델이면 잔차가 백색잡음에 가까워야 한다.

- 잔차 평균이 0 부근인가
- 잔차에 뚜렷한 패턴이 남아 있지 않은가
- 잔차의 ACF에 큰 자기상관이 남지 않는가

잔차에 패턴이 남아 있으면 차수 선택이 충분하지 않을 수 있다.

## 7. 이 예제 데이터에 연결해서 보기

대중교통 승차량 데이터는 보통 다음 특성을 가진다.

- 요일별 패턴이 강하다
- 주말/평일 구조가 다르다
- 7일 주기의 계절성이 존재할 가능성이 높다

그래서 다음 같은 접근이 자연스럽다.

1. 원본 시계열 확인
2. `diff(7)`로 주간 계절 차분을 살펴봄
3. 필요하면 `ARIMA` 또는 계절성을 포함한 `SARIMA` 구조 사용

현재 코드의:

```python
ARIMA(
    rail_series,
    order=(1, 0, 0),
    seasonal_order=(0, 1, 1, 7)
)
```

는 다음 의미에 가깝다.

- 일반적인 단기 자기회귀 효과는 일부 반영
- 7일 주기의 계절성은 계절 차분과 계절 MA로 반영

즉, 이 데이터에서 중요한 반복 패턴이 "7일 주기"라는 가정을 모델에 넣고 있는 것이다.

## 8. 정리

핵심은 이 한 줄이다.

`ARIMA`는 비정상 시계열을 무작정 처리하는 모델이 아니라, **차분을 통해 정상성에 가까운 상태로 만든 뒤 자기상관 구조를 모델링하는 방법**이다.

따라서 흐름은 항상 다음처럼 잡으면 된다.

1. 시계열 준비
2. 시각화
3. 정상성 검정
4. ACF/PACF 확인
5. 필요하면 차분
6. 다시 정상성 확인
7. ARIMA 적합
8. 잔차 검토

이 순서를 머리에 넣고 보면 `AR`, `ARMA`, `ARIMA`의 차이도 훨씬 덜 헷갈린다.
